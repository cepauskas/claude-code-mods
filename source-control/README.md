# Source Control pane

A Claude Code desktop mod that adds a VS Code-like Source Control pane beside the chat: staged and unstaged files grouped by directory, stage and unstage per file or all at once, click a file to open the app's diff pane, commit with a typed message, push (sets upstream when missing), switch or create branches, and discard a file's changes after confirmation. The pane refreshes every 3 seconds while visible and after Claude edits files.

## Install

See the README one folder up.

Reopen the pane any time with `/source-control` or the `⎇` button above the prompt.
